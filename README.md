# ECHO PROTOCOL: ARENA — канал обновлений

Здесь лежат только сборки игры. Исходники — в закрытом репозитории.

Игра сама проверяет `manifest.json` из последнего релиза и предлагает обновиться.
Ничего скачивать руками не нужно.

**Установить игру:** возьмите `EchoProtocol-Setup-*.exe` из
[последнего релиза](../../releases/latest) и запустите. После установки ярлык
появится на рабочем столе.
