# ECHO PROTOCOL: ARENA

**Финальная версия 1.0.2**

Соревновательный шутер: перестрелки в духе CS, способности как в Valorant,
паркур с тросом, киберпанк-аниме сеттинг. 16 карт, рейтинг с рангами, кейсы.

---

## Скачать и играть

### ⬇️ [СКАЧАТЬ УСТАНОВЩИК](https://github.com/Egoadsgoas/echo-protocol-updates/releases/latest/download/EchoProtocol-Setup.exe)

1. Скачайте файл по ссылке выше (~134 МБ).
2. Запустите его. Обычный мастер установки — папку можно выбрать любую.
3. После установки на рабочем столе появится ярлык **ECHO PROTOCOL ARENA**.
4. Запускайте и играйте.

Права администратора не нужны: по умолчанию игра ставится в вашу
пользовательскую папку.

> Windows может показать «Неизвестный издатель» — сборка не подписана
> сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

---

## Обновления

Ничего скачивать заново не нужно. Игра сама проверяет новые версии и
показывает баннер **«СРОЧНОЕ ОБНОВЛЕНИЕ»** — нажмите «Обновить сейчас»,
игра скачает обновление, перезапустится и продолжит работать.

**Прогресс не теряется.** Ранг, рейтинг MMR, оружие, скины, кейсы и поинты
хранятся отдельно от файлов игры и переживают любое обновление.

Обновляться обязательно: игроки на разных версиях не попадут в один матч.
Поэтому напоминание возвращается, пока обновление не поставлено.

## Как играть вместе

Один создаёт игру и передаёт остальным **код комнаты** или свой IP.
Работает по локальной сети и через проброс порта.

## Режимы и карты

| Режим | Карты |
|---|---|
| Свободный бой, дуэль, 2×2, 4×4 | 14 |
| Рейтинговая игра (5×5, ранги) | 11 |
| HVH Arena | 2 |
